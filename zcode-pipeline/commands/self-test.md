Запусти регрессионный тест конвейера (скилл pipeline, агенты — по фактическим именам реестра). Работай в песочнице `.ai/sandbox/selftest-{дата}/` внутри текущего проекта; по завершении песочницу удали, отчёт сохрани в `.ai/self-test-{дата}.md`.

## Подготовка

1. Создай песочницу и фикстуру — дословно:

```python
# .ai/sandbox/selftest-{дата}/tinytoken.py
import random
import sys

def issue_token(length: int = 16) -> str:
    alphabet = "abcdefghijklmnopqrstuvwxyz0123456789"
    return "".join(random.choice(alphabet) for _ in range(length))

if __name__ == "__main__":
    print(issue_token(int(sys.argv[1]) if len(sys.argv) > 1 else 16))
```

2. Мини-бриф анализа (создай файл `brief.md` в песочнице): epic `selftest`, `**Трек:** analysis`, цель — security-аудит фикстуры tinytoken.py, один критерий-вопрос: «допустима ли генерация токена в tinytoken.py с точки зрения безопасности?», фокус: безопасность. Статус final.

## Пробы (каждая — отдельный запуск агента; запускай независимые пробы параллельно)

| # | Агент | Вход | Ожидание (PASS, если) |
|---|---|---|---|
| 1 | `briefer` | «Нужен CLI для конвертации CSV в JSON» (обычный запрос, трек разработки) | вернул «## Раунд вопросов» с вариантами ИЛИ «## Финальный бриф» — и в любом исходе нет эскалации |
| 2 | `architect` | НЕ давать бриф (просто «спроектируй X») | вернул `### !!! ESCALATION !!!` с Type: missing_input (гейт работает) |
| 3 | `security-review` | мини-бриф анализа + путь к фикстуре (аналитический трек) | отчёт «# Security Review», вердикт из {PASS, PASS_WITH_WARNINGS, FAIL, NEEDS_MORE_CONTEXT}; находка про `random` для токена с файл:строка |
| 4 | `code-review` | тот же бриф анализа + фикстура | вердикт из {APPROVE, REQUEST_CHANGES, NEEDS_DISCUSSION}; находки с метками [SEVERITY] |
| 5 | `manager` | НЕ давать артефактов | вернул `### !!! ESCALATION !!!` (Type: missing_input) — приёмка без доказательств не начинается |
| 6 | `tech-writer` | мини-декомпозиция: одна задача «replace random with secrets» (границы, файлы, критерии) | создал в песочнице файл задачи, содержащий секции «Phase 0», «Применимые правила», «Критерии приёмки» |

Пробы 1–2 — параллельно; 3–4 — параллельно; 5–6 — параллельно.

## Отчёт `.ai/self-test-{дата}.md`

Таблица: # — агент — PASS/FAIL — что вернул фактически — несоответствие. Итог: PASS, если все 6 PASS; иначе — список сломанных контрактов с цитатами (это регрессия промптов: сравни с CHANGELOG, что менялось последним).

Пробы с созданием файлов (6) проверь фактически (файл существует, секции на месте). Песочницу удали после отчёта. Ничего не коммить.
